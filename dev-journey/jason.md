## Content 

**JSON** stands for **JavaScript Object Notation**. It is a simple text format used for store and send data. Manly used in modern APIs.

**Format:** an object -> {"key": "value"}

It is used for the API responses, for website communication.

**Data Type:** Object {}, Array [], String "", Number 123, Boolean true/false, Null Null

**Important Rules:** Key must "" double quotes, No comments allowed, Trailing commas are not allowed

**Nested Structure** It means objects and arrays can be nested inside each other, which create levels

**Metadata:** extra info about the result

**Objects & Array**
| |**Object\{\}**|**Array\(\)**|
|---|---|---|
|Access by| name\(key\)|Position\(index 1,2,3\)|
|Order|No guaranteed order|Keeps the order|
|Used When|Have the named fields|Have the list of similar things|

**Example:**

```
```jason
{
  "orders": [ ... ],
  "metadata": { ... },
  "totalResults": 2195
}

```
