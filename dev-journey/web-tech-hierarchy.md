## Web Tech Hierarchy

> **Level 1: Pure HTML + CSS**
> - Static pages written by hand
> - Simplest possible website
> - Good for: brochure sites, simple landing pages

> **Level 2: HTML + CSS + JavaScript**
> - Adds interactivity in the browser
> - Buttons, menus, simple dynamic behaviour
> - Good for: small interactive sites

> **Level 3: Server-side (PHP, etc.) + Database**
> - Server generates pages on request
> - Can pull data from a database
> - Good for: older dynamic business sites

> **Level 4: CMS (Content Management System)**
> - WordPress, Drupal, etc.
> - Admin panel + plugins (e.g. WooCommerce)
> - Good for: most small business websites and stores

> **Level 5: Modern Frameworks / Static Site Generators**
> - Astro, Next.js, Eleventy, Hugo, etc.
> - Code/templates → fast static or hybrid sites
> - Good for: fast marketing sites, blogs, modern custom sites

> **Level 6: Full-stack / App Frameworks**
> - Next.js, SvelteKit, Remix + backend
> - Complex logic, user accounts, real-time features
> - Good for: web apps, complex stores, SaaS

> **Level 7: Headless + Custom Architecture**
> - Framework frontend + separate backend/API + headless CMS
> - Maximum flexibility and performance
> - Good for: larger custom platforms and advanced e-commerce
