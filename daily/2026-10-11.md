# 2026-10-11

## 📚 What I learned today
- Installed Neovim on my MacBook Air with Homebrew, then settled on LazyVim as the starter config.
- Basics: normal / insert / visual modes, hjkl movement, and LazyVim's Space-leader shortcuts.
- File tree with `Space e`, window moves with Ctrl+h / Ctrl+l, and side-by-side splits with Ctrl+v (or `:vsplit`).
- Tree-sitter's YAML parser failed to build: Anaconda's old `ld` was winning on PATH, and the default MacOSX27.0 SDK didn't work with linker ld-1267 on macOS 26.7. Fix path was prefer `/usr/bin/ld`, set `SDKROOT` to the MacOSX26.5.sdk, clear the tree-sitter-yaml cache, then `:TSUpdate`. Stay on 26.7 for now.

## 🤔 What caught my interest
- Keyboard-first editing (want to use the mouse less). Tools mentioned alongside this: Raycast, Rectangle, Vimium, Homerow.
- Running code from LazyVim: Ctrl+/ did nothing in my setup; alternatives to try are `Space f t` / `Space f T` or `:terminal`.
